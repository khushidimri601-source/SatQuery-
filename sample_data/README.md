# Real satellite demo scenes

The previous synthetic block-colour demo images were removed. Use the downloader in the project root to fetch real public NASA Earth Observatory scenes.

Sources:
- Flood: Hurricane Laura, Landsat 8, Aug 13 / Aug 29 2020 — https://science.nasa.gov/earth/earth-observatory/flooding-blackouts-in-the-wake-of-laura-147204/
- Deforestation: Bolivia forest change, Landsat 5/8, 1986 / 2022 — https://earthobservatory.nasa.gov/images/150257/patterns-of-forest-change-in-bolivia
- Urban: Jakarta growth, Landsat/ASTER, 1976 / 1989 / 2004 — https://earthobservatory.nasa.gov/images/5693/urban-growth-in-jakarta-indonesia
- Agriculture: Soybean expansion in Brazil Cerrado, MODIS, 2001–2013 — https://earthobservatory.nasa.gov/images/85364/soybeans-in-the-brazilian-cerrado

These are real satellite observations. The application still treats RGB/JPEG analysis as screening unless compatible multispectral GeoTIFF data is supplied.
